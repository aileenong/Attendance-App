This is a face recognition attendance app with Streamlit and Supabase.  It has the following functions:
- Authentication (signup/login), profiles with roles - Admin will be able to capture samples and retrain the model with the samples captured.
- Admin dashboard for role management - enable select employees to become an admin.
- Employee registration, sample capture, retraining to Supabase Storage (Admin role only)
- Face attendance with clock‑in/out confirmation - employee can log attendance
- Timesheet calculation and reporting dashboard - calculate the attendance for the day or month.
